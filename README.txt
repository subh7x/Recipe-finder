# Recipe Finder

A mobile-first, GitHub Pages-ready recipe finder website.

## Files
- index.html — website structure
- style.css — responsive design and dark mode
- script.js — recipe database, filtering, serving scaling and recipe modal
- images/logo.png — branding asset

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload all files while preserving the `images` folder. In GitHub:
Settings → Pages → Deploy from branch → select `main` and `/ (root)` → Save.

The site uses Google Fonts, so an internet connection improves typography, but the app itself works without a backend.
